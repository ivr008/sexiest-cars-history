# The Sexiest Cars in History 🏆

A single-page hall of fame of 26 of the most beautiful cars ever built — from the 1928
Duesenberg Model J to the 2005 Bugatti Veyron — with photos, specs and stories.

## Run locally
Open `index.html`, or:

```bash
python3 -m http.server 8000
```

## Build
`index.html` is generated by `build.py` using image metadata in `meta.json`:

```bash
python3 build.py
```

## Images
Photographs come from Wikimedia Commons under their respective Creative Commons licences;
each card credits and links to its source.
